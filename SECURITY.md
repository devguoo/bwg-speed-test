# Security Policy

## Reporting Sensitive Information

If you notice exposed credentials, API keys, private account details, server login data or other sensitive information in this repository, please open a private report through GitHub's security reporting features if available, or contact the maintainer through the GitHub profile.

Do not post secrets in public issues.

## Repository Safety Rules

- Do not submit `.env` files, private keys, tokens, credentials or API configuration files.
- Do not include affiliate dashboard screenshots or private account screenshots.
- Use fake values in examples, such as `example_token` or `YOUR_API_KEY_HERE`.
- Keep scripts readable and avoid obfuscated commands.

## Supported Content

This repository contains public test targets, route-testing notes and documentation. It does not require users to provide credentials or private account data.
