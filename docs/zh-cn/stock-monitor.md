# 搬瓦工库存和补货怎么看

搬瓦工部分套餐会阶段性缺货。库存监控的作用不是替你判断最终是否购买，而是帮助你更快知道哪些套餐值得继续看、哪些应该准备替代方案。

## 看库存时先分清三件事

1. 有货不代表适合你。
2. 缺货不代表只能等。
3. 最终库存、价格、配置和付款周期以实际购买页为准。

## 推荐关注顺序

| 关注方向 | 适合情况 |
|---|---|
| 20G / 40G CN2 GIA-E | 新手入门、预算适中 |
| 香港 / 东京 / 大阪 CN2 GIA | 亚洲访问、延迟优先 |
| ECOMMERCE SLA | 长期项目、商业用途 |
| KVM PROMO | 预算敏感、备用节点 |
| 限量版套餐 | 有明确需求且愿意等待补货 |

## 缺货时怎么处理

不要只等待同一款补货。可以这样处理：

1. 记录你真正需要的预算、内存、流量和机房。
2. 找同系列相邻容量。
3. 找相邻机房。
4. 用推荐器生成替代方向。
5. 有货后再回到购买页核对最终信息。
