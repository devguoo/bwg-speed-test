# 搬瓦工套餐推荐器怎么用

套餐推荐器用于解决一个常见问题：不知道该先看 CN2 GIA-E、香港、东京、大阪、KVM PROMO 还是 ECOMMERCE SLA。

它不会替你最终下单，而是帮你缩小范围。

## 适合什么时候用

- 第一次买搬瓦工，不知道从哪一款开始看。
- 在多个机房之间犹豫。
- 首选套餐缺货，需要替代方案。
- 想按预算、访问区域和使用周期先做筛选。

## 推荐器会参考什么

推荐器主要参考：

- 主要用途；
- 访问区域；
- 预算倾向；
- 更重视价格、延迟、稳定性还是资源余量；
- 使用周期。

输出结果通常会给出一个优先方向和备选方向。你还需要进入套餐页确认库存、价格、付款周期和实际可选机房。

## 推荐结果怎么理解

| 推荐结果 | 通常代表 |
|---|---|
| 20G CN2 GIA-E | 入门、均衡、新手常见选择 |
| 香港 / 东京 / 大阪 | 亚洲访问、延迟优先 |
| KVM PROMO | 成本控制、轻量用途 |
| ECOMMERCE SLA | 长期项目、商业用途、稳定性优先 |

## 下一步

拿到推荐结果后，建议继续看：

- 套餐页是否有货；
- 对应容量是否满足你的网站或项目；
- 付款周期是否符合预算；
- 机房是否可以选择你想要的区域；
- 有没有更适合的同系列替代方案。
